# local_ai_session_timeline

AI 编码会话的**本地**留痕与回放工具 —— 零网络、零上传、零留存，构建产物是**唯一一个 HTML 文件，双击即开**。

## 为什么做这个

AI 编码工具会在本地留下会话记录（JSONL 日志）：你让它做了什么、它调了哪些工具、改了哪些文件、token 花在了哪。但这些日志躺在隐藏目录里，既不方便回看，也不方便复盘。

把日志拖进云端查看器？日志里可能有你公司的代码、路径和密钥，**不该为了「看看自己的会话」把它上传到任何地方**。

这个工具把「回看自己的 AI 编码会话」变成一个纯本地动作：拖入日志文件 → 时间线渲染 → 本地统计 → 需要时生成脱敏复盘包，由你自己复制到你自己选的账号去用。

## 设计红线

| 红线 | 含义 | 如何保证 |
|---|---|---|
| **零网络** | 工具从不发起任何网络请求 | CSP `connect-src 'none'` + 构建期静态审计，命中即 build 失败 |
| **零留存** | 不写 localStorage / 不落任何缓存 | 刷新即释放，数据只存在于内存 |
| **脱敏出口** | 复制/导出的内容走字段白名单 | API Key 掩码、路径脱敏、复盘包仅结构化字段（不含会话原文） |
| **单文件** | 构建产物只有 1 个 HTML | 双击即开（`file://`），无安装、无依赖、可被完整审计 |

> 本工具**不调用任何模型**：摘要与复盘提示词由本地确定性算法生成，如需 AI 参与复盘，请复制脱敏文本到你自己的模型账号执行。

## 如何自证「零网络」

适用于首个 Release 发布的产物文件：

1. 从 Release 下载**唯一**的 HTML 文件（附带 SHA-256 校验值）；
2. 用浏览器 DevTools 的 Network 面板录制：双击打开 → 拖入日志 → 全部功能走一遍 —— **0 条非 `file://` 请求**；
3. 检查文件内的 URL：全文件裸 `grep` 会看到许可注释块（`LICENSE_NOTICE_BEGIN` … `LICENSE_NOTICE_END`）里的法律文本 URL —— 那是 PolyForm / 第三方许可证原文与 `Required Notice` 的**字面文本，不是网络引用**，浏览器从不加载 HTML 注释；剥离该块后再扫，禁用模式只剩页脚赞助链接 1 条命中；
4. 或直接运行仓库内的 `npm run verify:offline`，与手工步骤用同一把尺。
